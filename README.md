## Featured projects

### [AI Job Match Agent](https://github.com/caraqueleonardoAlfredo/ai-research-agent)
Autonomous agent built with **LangGraph** that searches for current job opportunities, extracts structured requirements, compares them with a candidate's technical profile, and produces a prioritized ranking.

`Python` `LangGraph` `LangChain` `Claude` `Tavily` `Pydantic`

### [AI Document RAG Chat](https://github.com/caraqueleonardoAlfredo/ai-doc-rag-chat)
Document question-answering application using semantic retrieval, multilingual embeddings, ChromaDB, and transparent source display. The retrieval pipeline was improved from **Recall@3 = 0.29** to **Recall@5 = 0.71**.

`Python` `RAG` `ChromaDB` `Sentence Transformers` `Claude` `Streamlit`

### [AI Evaluation Harness](https://github.com/caraqueleonardoAlfredo/ai-eval-harness)
Reusable evaluation toolkit for RAG systems and AI agents, combining objective retrieval metrics with structured **LLM-as-judge** evaluation.

`Python` `LLM Evaluation` `Recall@K` `LLM-as-Judge` `Pydantic`

### [AI Job Extractor API](https://github.com/caraqueleonardoAlfredo/ai-job-extractor-api)
FastAPI service that converts unstructured job descriptions into validated structured data using Claude and Pydantic.

`Python` `FastAPI` `Pydantic` `Anthropic API` `Structured Outputs`

### [AI Job Relevance Classifier — QLoRA](https://github.com/caraqueleonardoAlfredo/ai-fine-tuning-lora)
Fine-tuned **Qwen2.5-1.5B-Instruct** with QLoRA for job-relevance classification, including dataset generation, training, and comparative evaluation.

`Python` `Transformers` `PEFT` `TRL` `QLoRA` `Qwen`

### [AI Job Extractor — MCP Server](https://github.com/caraqueleonardoAlfredo/ai-mcp-server)
Model Context Protocol server that exposes structured job extraction as a reusable AI tool through **FastMCP**.

`Python` `MCP` `FastMCP` `Pydantic` `Claude`

### [Dianuby Mirror AI](https://github.com/caraqueleonardoAlfredo/EspejoIA)
Interactive smart mirror integrating embedded electronics, Raspberry Pi, presence and gesture sensors, voice interaction, Flask APIs, Home Assistant, Zigbee, and an AI-ready response layer.

`Python` `Flask` `Raspberry Pi` `GPIO` `IoT` `Home Assistant` `Zigbee`
